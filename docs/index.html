The premise

Your Mac is already signed in,
always on, and capable.

Help Me Bruh connects that machine to the place people already reach you: iMessage. No new app. No second phone number. No black-box service holding the keys.

03
⌂

Local by default.
Open by design.

The bridge runs as a LaunchAgent on your Mac. Read the code, change the tools, or remove it completely.

Up and running

One Mac.
Four steps.

  1. 1
    Sign in

    Keep Messages signed in on the Mac that will run the assistant.

  2. 2
    Clone + connect

    Install dependencies and use your existing ChatGPT/Codex login. API providers stay optional.

  3. 3
    Grant access

    Give Node Full Disk Access so it can read the local Messages database.

  4. 4
    Text /bruh

    The LaunchAgent starts at login and replies from your existing iMessage account.
